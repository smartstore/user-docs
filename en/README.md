# Welcome

[Smartstore](https://smartstore.com/en/) is an open-source e-commerce platform for setting up and running online stores. With Smartstore, you can manage products, orders, and customers, create content, and set up marketing, payment methods, and shipping. Plugins let you add features and tailor your store to your needs.

This documentation takes you from your first look at Smartstore through setup and day-to-day store management. Choose the area that matches what you want to do.
