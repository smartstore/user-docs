# Shortcuts

**CTRL+S:** Save

**ENTER:** Confirm, open block edit mode

**DEL:** Delete

**CTRL+Z:** Undo

**CTRL+Y:** Redo

**CTRL+ALT+P:** Preview mode

**CTRL+F11:** Fullscreen mode
