# Reward Point Settings

![](<../../../.gitbook/assets/reward-points1.png>)

| Input field | Explanation |
| :--- | :--- |
| Enabled | Check the box if you want to enable the reward points program. |
| Exchange rate | Specify the reward points exchange rate (e.g. 1 reward point = 1.00 EUR). |
| Round down points | If active, points will be rounded down to the nearest integer. |
| Points for registration | Specify the number of points awarded for registration. |
| Points for a product review | Specify the number of points awarded for adding an approved product review. |
| Show points for a product review | If enabled, displays the potential reward points for a review to the customer. |
| Points for purchases | Specify the number of points awarded for purchases (e.g. 1 point for every 10.00 EUR spent). |
| Round down the amount of points for a purchase | If active, the calculated points for a purchase are rounded down. |
| Show points for the purchase of a product | If enabled, shows how many points a customer can earn by purchasing a specific product on the detail page. |
| Awarded order status | Points are awarded when the order reaches this status (e.g. Complete). |
| Canceled order status | Points are canceled when the order reaches this status (e.g. Cancelled). |
