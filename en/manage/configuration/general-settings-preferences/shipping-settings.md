# Shipping Settings

![](<../../../.gitbook/assets/shipping settings1.png>)

| Input field | Explanation |
| :--- | :--- |
| Free shipping over 'X' | Check the box to enable free shipping for all orders over ‘X’. Set the value for X below. |
| Calculate shipping costs during checkout | If enabled, shipping costs are calculated and displayed during the checkout process. |
| Shipping origin determines shipping costs if shipping address is missing | If the customer hasn't entered a shipping address yet, the shipping costs will be calculated based on the store's shipping origin. |
| Estimate shipping enabled | Check the box to allow customers to estimate shipping on the shopping cart page. If this option is activated, the order summary on the first checkout page renders a control which can be used by your customers to estimate the shipping costs. |
| Display shipment events | Check the box if you want your customers to see shipment events on their shipment details page (if supported by your shipping rate computation method). |
| Display shipping options during checkout process only if more than one option is available | If enabled, the shipping method selection step is skipped during checkout if only one option is available. |
| Charge the highest shipping surcharge only | If multiple items in the cart have shipping surcharges, only the highest surcharge will be applied to the total shipping cost. |
| Shipping origin | Define the origin address (Country, State/province, Zip/postal code) used for shipping calculations. |
