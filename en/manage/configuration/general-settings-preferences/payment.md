# Payment

![](<../../../.gitbook/assets/payment-settings.png>)

| Input field | Explanation |
| :--- | :--- |
| Capture payment amount when... | Determines the event when the payment amount is automatically captured. The selected payment method must support bookings for this. |
| Payment method icons on the product detail page | Determines for which payment methods icons are displayed on product detail pages to inform customers about accepted payment options. |
| Show icons on the payment method selection page | Specifies whether icons should be displayed next to the payment methods during checkout. |
| Only display payment method selection if more than one payment method is available | If enabled, the payment selection step is skipped during checkout if only one payment method is available. |
