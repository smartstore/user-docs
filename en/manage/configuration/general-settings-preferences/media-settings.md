# Media Settings

![](<../../../.gitbook/assets/media settings1.png>)

## General

| Input field | Explanation |
| :--- | :--- |
| Generate absolute URLs | Specifies whether to generate absolute URLs for media resources. |
| Automatically delete orphaned files | If enabled, files that are no longer associated with any record will be deleted automatically to save space. |
| Enable image zoom | Check this box to enable the zoom feature for product images on detail pages. |
| Maximum file size | The maximum file size (in KB) allowed for media uploads. |
| Maximum image size | The maximum dimension (longest side in pixels) allowed for uploaded images. Larger images will be resized down to this value. |

## Image/thumbnail sizes

Defines the default dimensions (in pixels) for images used in various parts of the store.

| Input field | Explanation |
| :--- | :--- |
| Gallery thumbnail | Size of thumbnails in the product image gallery. |
| Product list | Size of product images displayed in product lists (e.g. category pages, search results). |
| Product detail | Size of the main product image on the product detail page. |
| Associated (grouped) product | Size of images for associated products within a grouped product. |
| Associated (grouped) product in the header | Size of associated product images displayed in the header area. |
| Bundle items | Size of images for items included in a product bundle. |
| Products in e-mails | Size of product images displayed in transactional emails. |
| Categories | Size of category thumbnail images. |
| Brands | Size of manufacturer/brand thumbnail images. |
| Cart | Size of product images in the shopping cart and wishlist. |
| Bundle items in cart | Size of bundle item images in the shopping cart. |
| Mini cart | Size of product images in the mini-shopping cart (flyout). |
| Customer avatar | Size of customer avatar images. |

## Media types

Controls which file extensions are allowed for uploads. Separate extensions with spaces.

| Input field | Explanation |
| :--- | :--- |
| Image | Allowed file extensions for image uploads (e.g. bmp, gif, jpeg, jpg, png, webp). |
| Video | Allowed file extensions for video uploads. |
| Audio | Allowed file extensions for audio uploads. |
| Document | Allowed file extensions for document uploads (e.g. pdf, doc, docx, xlsx). |
| Text | Allowed file extensions for text files. |
| Other | Allowed file extensions for other file types. |



## Storage

![](<../../../.gitbook/assets/media-storage.png>)

| Input field | Explanation |
| :--- | :--- |
| Change storage | Allows you to change the storage location for media files (e.g. Database or File system). <br><br>**Important:** Do not forget to backup your database before changing this option! The operation moves all existing files to the new location and can take several minutes. |
