# Blog Settings

![](<../../../.gitbook/assets/blog settings.png>)

| Input field | Explanation |
| :--- | :--- |
| Blog enabled | Check the box to enable the blog in your store. |
| Allow not registered users to leave comments | Check the box to allow non-registered users to leave comments. |
| Allow customers who have never purchased to leave comments | Check the box to allow customers to leave comments even if they have never purchased an item. |
| Notify about new blog comments | Check the box to notify the store owner about new blog comments. |
| Navigation End Date | Defines the date until which the blog link appears in the shop navigation. |
| Layout | Select the visual layout for the blog listing (e.g. Masonry). |
| Columns | Determines the grid layout and sidebar position (e.g. Two posts per row + blog sidebar). |
| Posts per page | Set the number of posts displayed per page. |
| Intro | Controls how much of the blog post content is shown in the list view (e.g. Show all). |
| Display intro on mobile devices | Check the box to show the intro text on mobile devices as well. |
| Number of tags (cloud) | The number of blog tags that appear in the tag cloud. |
| RSS feed | Check the box to generally enable the RSS feed for the blog. |
| Maximum age (in days) | Specifies the maximum age (in days) for posts to be included in the RSS feed. |
| Display blog RSS feed link in the browser address bar | Check the box to enable the blog RSS feed link in the customer's browser address bar. |
