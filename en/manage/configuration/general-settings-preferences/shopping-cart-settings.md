# Shopping Cart Settings

![](<../../../.gitbook/assets/Shoping Cart.png>)


| Input field | Explanation |
| :--- | :--- |
| Display cart after adding product | If checked, customers will be redirected to the shopping cart page immediately after adding a product. Otherwise, they remain on the current page. |
| Maximum shopping cart items | Maximum number of distinct products allowed in a shopping cart. |
| Show product images on cart | Determines whether product images should be displayed in the shopping cart. |
| Show product images of bundle items on cart | Determines whether product images of bundle items should be displayed in the shopping cart. |
| Show discount box | Check this box to display the discount coupon box on the shopping cart page. |
| Show gift card box | Check this box to display the gift card box on the shopping cart page. |
| Number of 'Cross-Sells' | The number of ‘Cross-Sell’ products to display on the shopping cart page. Enter 0 to disable cross-sells. |
| Show mini-shopping cart | Check this box to enable the mini-shopping cart (flyout). |
| Mini-shopping cart product number | Specifies the maximum number of products displayed in the mini-shopping cart block. |
| Show product images in mini-shopping cart | Determines whether product images are displayed in the mini-shopping cart block. |
| Show legal hints in the shopping cart | Determines whether legal hints are shown in the order summary on the cart page. This text can be edited in language resources. |
| Display delivery times | Determines whether delivery times are displayed in the shopping cart. |
| Display product short description | Determines whether to display the product short description in the order summary. |
| Display base price | Determines whether the base price is displayed in the shopping cart. |
| Show product weight in shopping cart | Determines whether the product weight is shown in the shopping cart. |
| Show quantity of linked product | Determines whether the quantity of linked products appears at a variant attribute value. |
| Show comment box on shopping cart page | Determines whether the comment box is displayed on the shopping cart page. |
| Round prices during calculation | Determines whether the shop calculates with rounded price values (recommended for B2B). |

## Checkout

![](<../../../.gitbook/assets/Shoping Cart1.png>)

| Input field | Explanation |
| :--- | :--- |
| Checkout process | Choose between the standard checkout and other installed checkout flows. |
| Quick Checkout | If enabled, the "Quick Checkout" button is displayed, allowing customers to skip the cart and go directly to checkout. |
| Customers can change their preferred shipping method | Allows customers to change their pre-selected shipping method during checkout. |
| Customers can change their preferred payment method | Allows customers to change their pre-selected payment method during checkout. |
| Show comment box | Determines whether the customer can leave a comment about their order on the confirmation page. |
| Subscribe to newsletters | Determines if and how the newsletter subscription option is shown during checkout (e.g., "Do not show", "Checked by default", "Unchecked by default"). |
| Second buy-button below cart | Displays a second "Buy" button below the order summary for better usability on long pages. |
| Show legal hints in order summary | Determines whether legal hints are shown in the order summary on the confirmation page. |
| Show revocation waiver box for electronic services | Determines whether the customer must agree to a revocation waiver for electronic services on the confirmation page. |
| Consent for email transfer to third parties | Determines if customers can agree to passing their email to third parties (e.g. for shipping notifications) and the default state of the checkbox. |

## Wishlist

![](<../../../.gitbook/assets/Shoping Cart2.png>)

| Input field | Explanation |
| :--- | :--- |
| Display wishlist after adding product | If checked, customers will be redirected to the wishlist page immediately after adding a product. Otherwise, they remain on the current page. |
| Allow 'out of stock' items to be added to wishlist | Check this box to allow out-of-stock products to be added to the wishlist. |
| Maximum wishlist items | Maximum number of distinct products allowed in a wishlist. |
| Show product images on wishlist | Determines whether product images are displayed on customer wishlists. |
| Show product images of bundle items on wishlist | Determines whether product images of bundle items are displayed on customer wishlists. |
| Allow customers to email their wishlists | Check this box to allow customers to email their wishlists to friends. |
| Allow guests to email their wishlists | Check this box to allow guests to email their wishlists to friends. |
