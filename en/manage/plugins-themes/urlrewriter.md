## Configuration of the UrlRewriter Plugin

| **Input field / Option** | **Description** |
| ------------------------ | ---------------------------------------------------- |
| Is active                | Determines whether the redirection rules are active. |
| Rewrite rules            | Enter one rewrite rule per line.                     |
