# Brevo

The paid **Brevo Email Synchronization** plugin connects Smartstore's newsletter management with the Brevo email marketing service, formerly Sendinblue. Newsletter subscriptions and unsubscribes from Smartstore are synchronized with a selected Brevo contact list. Unsubscribes made directly in Brevo can be reported back to Smartstore through a webhook.

{% hint style="info" %}
The plugin synchronizes newsletter subscribers, but it does not create or send campaigns. Campaigns are managed directly in Brevo. For information about Smartstore's integrated newsletter feature, see [Managing Newsletter Campaigns](../marketing-promotions/managing-newsletter-campaigns.md).
{% endhint %}

To use the plugin, you need:

- an active Brevo account
- a Brevo API key version 3
- at least one contact list in Brevo
- a valid license for the Brevo plugin.

For Brevo to send unsubscribes to Smartstore, the webhook URL provided by Smartstore must be accessible from Brevo.

For more information about installing and licensing paid plugins, see [Installing Plugins](installing-plugins.md) and [Managing Plugins](managing-plugins.md).

## Features

The plugin synchronizes newsletter subscriptions and unsubscribes based on the email address.

| Direction | Event | Behavior |
|---|---|---|
| Smartstore to Brevo | Newsletter subscription | The contact is created or updated in Brevo and added to the selected contact list. |
| Smartstore to Brevo | Newsletter unsubscribe | The contact is removed from the selected contact list. |
| Brevo to Smartstore | Unsubscribe in Brevo | The newsletter subscription is removed from Smartstore through the Brevo webhook. |
| Smartstore to Brevo | Initial synchronization | All active newsletter subscribers for the selected store are added to the synchronization queue. |

{% hint style="info" %}
The plugin transfers email addresses only. Names, addresses, orders, other customer data, and contact attributes are not synchronized with Brevo.
{% endhint %}

An unsubscribe in Smartstore removes the contact from the configured Brevo list. It does not delete the contact from the Brevo account.

## Configuration

Under **Plugins > Manage Plugins**, open the configuration for the **Brevo Email Synchronization** plugin. Here you connect Smartstore to your Brevo account, select the target contact list, and configure ongoing synchronization.

![Brevo plugin configuration with API key, target list, and automatic synchronization](../../.gitbook/assets/module_brevo_configuration.png)

| Setting | Description |
|---|---|
| **Brevo API Key (v3)** | API key for the connection between Smartstore and Brevo. You create and manage the key in your Brevo account. |
| **Brevo Target List** | Contact list to which new newsletter subscribers are added. Unsubscribes remove the contact from this list. |
| **Auto Sync** | Activates the background task for regular synchronization with Brevo. The task runs once per hour. |
| **Webhook URL** | Address generated by Smartstore to which Brevo sends unsubscribes. The URL can be copied but cannot be edited manually. |
| **Manual Synchronization** | Shows the number of pending subscriptions and unsubscribes and processes the queue immediately. |
| **Initial Synchronization** | Adds all currently active newsletter subscribers for the selected store to the queue. |

### Connecting to Brevo

1. Open [API Keys](https://app.brevo.com/settings/keys/api) in Brevo.
2. Create or copy an API key version 3.
3. Enter the key under **Brevo API Key (v3)**.
4. Click **Save**.
5. Check the displayed connection status.
6. Under **Brevo Target List**, select the required contact list.
7. Save the configuration again.

Brevo lists can only be retrieved after an API key has been saved.

{% hint style="info" %}
The plugin retrieves up to 50 contact lists from the Brevo account. If an existing list is not available for selection, check the API key and the number of lists in Brevo.
{% endhint %}

{% hint style="warning" %}
Treat the API key as confidential. Do not publish it, and only share it with people who require access to the Brevo integration.
{% endhint %}

## Initially synchronizing existing subscribers

After configuring the API key and target contact list, you can transfer the newsletter subscribers already stored in Smartstore.

![Initial synchronization and queue for the Brevo plugin](../../.gitbook/assets/module_brevo_initial_synchronization.png)

1. In a multi-store installation, first select the required store.
2. In the **Initial Synchronization** section, check the number of active subscribers.
3. Click **Run now** in this section.
4. Then process the queue through **Manual Synchronization**, or enable **Auto Sync**.

{% hint style="info" %}
Initial synchronization first adds the active subscribers to the queue. They are not transferred to Brevo until the queue is processed manually or by the background task.
{% endhint %}

You can run the initial synchronization again when required. Contacts that already exist in Brevo are updated and assigned to the selected list.

## Ongoing synchronization

After the initial synchronization, the plugin automatically records new newsletter subscriptions and unsubscribes in a local queue. The queue can be processed automatically or manually.

### Automatic synchronization

Enable **Auto Sync** so that Smartstore regularly processes the queue in the background. The corresponding **Brevo subscriber sync** task runs once per hour.

You can check the task status, last execution, and possible errors under **System > Scheduled Tasks**. For more information, see [Managing Scheduled Tasks](../system-maintenance/managing-scheduled-tasks.md).

{% hint style="info" %}
Synchronization does not take place in real time. New subscriptions and unsubscribes remain in the queue until the next task execution.
{% endhint %}

### Manual synchronization

The **Manual Synchronization** section shows how many subscriptions and unsubscribes have been waiting for transfer since the last synchronization.

![Manual synchronization with pending subscriptions and unsubscribes](../../.gitbook/assets/module_brevo_manual_synchronization.png)

Click **Run now** to process the pending changes immediately. Manual synchronization is only available after a Brevo target list has been selected.

After successful processing, Smartstore displays the number of updated contacts.

## Setting up the webhook

The webhook reports unsubscribes from Brevo back to Smartstore. Without this webhook, unsubscribes performed directly in Brevo are not automatically reflected in Smartstore's newsletter management.

1. Copy the address shown under **Webhook URL**.
2. Open [Webhooks](https://app.brevo.com/settings/webhooks) in Brevo.
3. Create a new webhook.
4. Enter the URL provided by Smartstore as the target address.
5. Enable the **unsubscribe** event for the webhook.
6. Save the webhook.
7. Test the processing with a suitable test address.

Smartstore only processes Brevo events of type `unsubscribe` through this endpoint. The plugin ignores other Brevo events.

When Brevo reports an unsubscribe, Smartstore immediately removes the corresponding newsletter subscription. No additional unsubscribe confirmation is sent.

{% hint style="warning" %}
Make sure you copy the complete webhook URL. In a multi-store installation, the address contains the ID of the store whose newsletter subscriber should be removed.
{% endhint %}

## Multi-store configuration

In a multi-store installation, settings can be configured globally or for a specific store. Before configuring the plugin, use the store selector to choose the required store.

For more information about global and individual settings, see [Defining the Scope of Settings](../configuration/general-settings-preferences/defining-the-scope-of-settings.md).

The following points are particularly important for the Brevo configuration:

- Initial synchronization considers the active newsletter subscribers for the selected store.
- The displayed webhook URL contains the ID of the selected store.
- The appropriate webhook URL must be configured in Brevo for each store.
- Before running an initial synchronization, always check which store is currently selected.

{% hint style="warning" %}
For each store, use the webhook URL displayed on that store's configuration page. A URL containing the wrong store ID can prevent an unsubscribe from being assigned to the expected store.
{% endhint %}

For basic information about configuring multiple stores, see [Working with Multiple Stores](../../discover/common-concepts/working-with-multiple-stores.md).

## Checking newsletter subscribers in Smartstore

The subscriptions and unsubscribes synchronized by Brevo relate to Smartstore newsletter subscribers.

Open **Marketing > Newsletter Subscribers** to check the subscribers stored locally. There you can determine whether a subscription is active or whether an unsubscribe reported through the Brevo webhook has been removed.

For more information about managing, importing, or exporting newsletter subscribers, see [Managing Newsletter Campaigns](../marketing-promotions/managing-newsletter-campaigns.md#manage-subscribers).

## Privacy

During synchronization, Smartstore transfers newsletter subscriber email addresses to Brevo. Include Brevo in your store's privacy information and inform affected people about the nature and purpose of this data transfer.

The plugin does not transfer names, addresses, orders, or other customer data. Email campaigns are created, managed, sent, and analyzed outside Smartstore in the Brevo account.

Also verify that the consent and unsubscribe processes used in Smartstore are suitable for the intended use in Brevo.

## Troubleshooting

### The connection to Brevo cannot be established

- Check that a Brevo API key version 3 has been entered.
- Remove accidental spaces at the beginning or end of the key.
- Save the configuration before checking the connection again.
- Make sure the API key is still active in the Brevo account being used.
- Create a new API key if required.

### No contact lists are displayed

- Check the connection to the Brevo account.
- Make sure at least one contact list exists in the Brevo account.
- Note that the plugin retrieves up to 50 lists from the Brevo account.
- Save the API key and reopen the configuration page.

### The synchronization buttons are disabled

First select a **Brevo Target List** and save the configuration. Manual and initial synchronization cannot be started without a target list.

### Changes remain in the queue

- Start the synchronization manually.
- Check whether **Auto Sync** is enabled.
- Under **System > Scheduled Tasks**, check the **Brevo subscriber sync** task.
- Check the API key and the selected target list.
- Check whether the plugin is licensed for the relevant store.
- Check the system log for errors related to Brevo synchronization.

For more information about checking and manually running background tasks, see [Managing Scheduled Tasks](../system-maintenance/managing-scheduled-tasks.md).

### Unsubscribes from Brevo are still present in Smartstore

- Check whether the webhook is configured and enabled in Brevo.
- Check whether the **unsubscribe** event has been selected.
- Compare the URL configured in Brevo with the webhook URL displayed in Smartstore.
- If you have multiple stores, make sure you use the URL for the correct store.
- Make sure the webhook URL can be reached from Brevo.
- Check whether the email address exists as a newsletter subscriber in the relevant store.
