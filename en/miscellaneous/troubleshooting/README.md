# Troubleshooting

## Clear cache

If you are having problems with your shop, you can often solve them by [clearing the cache](../../manage/system-maintenance/clearing-cache.md). Try this first.

## Cloudflare

Problems with Cloudflare can be caused by caching, blocked automated tasks, or an incorrectly identified visitor IP address.

Recommended settings and solutions can be found in [the Cloudflare article](../integrations/cloudflare.md).

## Google reCAPTCHA is not working

After switching or reconfiguring Google reCAPTCHA V3, it may happen that forms such as the contact form or registration form cannot be sent. In many cases, the reCAPTCHA script is blocked by an incorrect key configuration without a visible error message appearing in the shop.

A detailed description of the cause and solution can be found under [Google reCAPTCHA V3 Error](google-recaptcha-v3-error.md).

## Summernote Font-Tools deactivated

In Smartstore Version 6, the functions for directly selecting a font and font size in the HTML editor have been deactivated. This change was made to ensure clean HTML code, better search engine optimization, and consistent content appearance.

If you need the font tools or want to implement individual formatting in the editor, more information and adjustment options can be found under [Summernote Font Tools Deactivated](summernote-font-tools-deactivated.md).
