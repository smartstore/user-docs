# Support erhalten

## Serviceprogramm

Für einen schnellen und professionellen Start bietet Smartstore verschiedene Serviceleistungen an, darunter Installation und individuelle Designanpassungen. Weitere Informationen finden Sie auf [unsere Webseite](https://smartstore.com/de/support/services).

## Support

Für Entwickler, Agenturen und Endnutzer stehen unterschiedliche Supportprogramme zur Verfügung. So können Sie **den Support buchen, der zu Ihrem Bedarf passt.** Mit einem Supportvertrag erhalten Sie darüber hinaus exklusive Premium-Plugins. Weitere Informationen finden Sie auf [unsere Webseite](https://smartstore.com/de/wartungsvertraege/).

## Unterstützung durch die Community

Auch ohne Supportvertrag können Sie [unsere Foren](http://community.smartstore.com/index.php?%2Fforum%2F85-smartstorenet-english%2F=\&k=4bece6ba3e2c18927fe32d654cb5d9ba\&setlanguage=1\&cal_id=\&langid=1) nutzen, um Fragen zu stellen und nach vorhandenen Lösungen zu suchen.
