# Wie kaufe ich eine Erweiterung?

Für den Kauf einer Erweiterung (Plugin, Theme oder Sprachressource) benötigen Sie einen PayPal-Account. Öffnen Sie im Smartstore Community Marketplace die Detailseite der gewünschten Erweiterung und klicken Sie auf **In den Warenkorb**. Geben Sie anschließend die Shop-URL an, für die die Erweiterung registriert werden soll. Danach gelangen Sie zum Warenkorb mit einer Übersicht Ihrer ausgewählten Erweiterungen.

Klicken Sie auf **Zur Kasse**, akzeptieren Sie unsere AGB und klicken Sie auf **Kaufen**. Anschließend werden Sie zu PayPal weitergeleitet. Nach erfolgreicher Zahlung gelangen Sie zurück zum [Smartstore Community Marketplace](http://community.smartstore.com/marketplace), wo Sie die Erweiterung herunterladen können.

Ihre Käufe finden Sie über Ihr Profil oben rechts in der Community. Wählen Sie dort **Kundenmenü** und anschließend den Reiter **Einkäufe**. Dort sehen Sie alle gekauften Erweiterungen und können sie über die jeweilige Detailansicht erneut herunterladen.
