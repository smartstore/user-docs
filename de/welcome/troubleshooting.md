# Troubleshooting

## Cache löschen

Sollten Sie ein Problem mit Ihrem Shop haben, kann es oftmals mit der Bereinigung des Caches behoben werden. Versuchen Sie daher als Erstes den [Cache zu löschen](../benutzer-handbuch/system-wartung/cache-bereinigen.md).

## Cloudflare

Bei der Verwendung von Cloudflare können Probleme durch **Caching**, **blockierte automatisierte Aufgaben** oder **eine falsch erkannte Besucher-IP** entstehen.

Die empfohlenen Einstellungen und Lösungen finden Sie im Beitrag [Cloudflare](../verschiedenes/integrationen/cloudflare.md).

## Google reCAPTCHA funktioniert nicht

Nach der Umstellung oder Neukonfiguration von Google reCAPTCHA V3 kann es vorkommen, dass Formulare wie Kontaktformular oder Registrierung nicht mehr abgesendet werden. Häufig wird dabei das reCAPTCHA-Skript durch eine fehlerhafte Key-Konfiguration blockiert, ohne dass im Shop eine sichtbare Fehlermeldung erscheint.

Eine ausführliche Beschreibung der Ursache und Lösung finden Sie unter [Google reCAPTCHA V3 Fehler](../verschiedenes/troubleshooting/google-recaptcha-v3-fehler.md).

## Summernote Font-Tools deaktiviert

In Smartstore Version 6 wurden die Funktionen zur direkten Auswahl von Schriftart und Schriftgröße im HTML-Editor deaktiviert. Dies ist eine bewusste Änderung, um sauberen HTML-Code, eine bessere Suchmaschinenoptimierung und ein einheitliches Erscheinungsbild von Inhalten zu gewährleisten.

Falls die Font-Tools weiterhin benötigt werden oder individuelle Formatierungen im Editor umgesetzt werden sollen, finden Sie weitere Informationen und Anpassungsmöglichkeiten unter [Summernote Font-Tools deaktiviert](../verschiedenes/troubleshooting/summernote-font-tools-deaktiviert.md).
