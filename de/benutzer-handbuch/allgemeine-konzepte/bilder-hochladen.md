# Bilder hochladen

Bilder können verschiedenen Objekten, die Sie in Ihrem Shop anlegen, hinzugefügt werden (z. B. Produkten, Warengruppen oder dem Content Slider). Zum Hochladen verwenden Sie immer dasselbe Werkzeug: den **Picture Uploader**. Mit dem Picture Uploader können Sie Bilder über den Dateimanager Ihres Betriebssystems oder per Drag-and-drop hinzufügen. Um den Dateimanager zu verwenden, klicken Sie auf **Zum Hochladen Dateien hier ablegen oder klicken.** Alternativ ziehen Sie ein Bild per Drag-and-drop auf diese Fläche. Bei mehreren Bildern können Sie die Reihenfolge ebenfalls per Drag-and-drop ändern. Sie können ein Bild als Hauptbild kennzeichnen und es auf Wunsch von der Anzeige in der Produktdetailgalerie ausschließen. Bewegen Sie zum Löschen den Mauszeiger über das Bild und klicken Sie auf **Entfernen**.\
Hochgeladene Bilder werden im Dateisystem oder in der Datenbank gespeichert, je nachdem, was Sie in [Medien-Einstellungen](../konfiguration/einstellungen/medien-einstellungen.md) festgelegt haben.
