# Bilder hochladen

Bilder laden Sie an verschiedenen Stellen im Backend hoch und ordnen sie Shopinhalten zu. Bei Warengruppen und Herstellern wählen Sie jeweils ein Bild aus. Bei Produkten können Sie mehrere Bilder hinzufügen und ihre Reihenfolge festlegen.

## Einzelnes Bild hochladen

Wenn Sie etwa einer Warengruppe oder einem Hersteller ein Bild hinzufügen möchten, klicken Sie auf **Zum Hochladen Dateien hier ablegen oder klicken** und wählen eine Bilddatei auf Ihrem Computer. Sie können jeweils nur ein Bild zuordnen. Möchten Sie es austauschen, laden Sie an derselben Stelle ein neues hoch.

## Mehrere Produktbilder hochladen

Speichern Sie ein neues Produkt zuerst. Öffnen Sie anschließend den Bereich für Produktbilder. Klicken Sie auf **Zum Hochladen Dateien hier ablegen oder klicken** und wählen Sie eine oder mehrere Bilddateien aus. In diesem Bereich können Sie Bilder auch per Drag-and-drop auf die Uploadfläche ziehen.

Die hochgeladenen Bilder erscheinen als Vorschaubilder. Ziehen Sie sie am Griff in die gewünschte Reihenfolge. Mit **Zum Hauptbild machen** legen Sie fest, welches Bild zuerst angezeigt wird. Aktivieren Sie **Erstes Bild aus Gallerie ausschließen**, wenn das erste Bild nur als Vorschau in Produktlisten und nicht in der Produktdetailgalerie erscheinen soll. Das greift nur, wenn weitere Bilder vorhanden sind.

Um ein Bild vom Produkt zu entfernen, bewegen Sie den Mauszeiger über sein Vorschaubild und klicken auf **Entfernen**. Dabei wird die Zuordnung zum Produkt gelöscht. Die Mediendatei bleibt erhalten.

## Vorhandene Bilder aus dem Medien-Manager auswählen

Wenn der [Medien-Manager](../plugins/mediamanager.md) verfügbar ist, klicken Sie bei der Bildauswahl auf **Medien durchsuchen...**. So wählen Sie eine bereits hochgeladene Datei aus. Bei Warengruppen und Herstellern wählen Sie ein Bild; bei Produktbildern können Sie mehrere Bilder auswählen. Im Medien-Manager können Sie Dateien auch hochladen und organisieren.

{% hint style="info" %}
Der Medien-Manager ist ein kostenpflichtiges Enterprise-Plugin. Die Schaltfläche erscheint nur, wenn das Plugin installiert und lizenziert ist und Sie die erforderliche Berechtigung haben.
{% endhint %}

## Speicherort und Uploadgrenzen

In den [Medien-Einstellungen](../konfiguration/einstellungen/medien-einstellungen.md) bestimmen Sie den Speicherort sowie die maximale Dateigröße und Bildabmessung für Uploads. Je nach Einstellung speichert Smartstore die Dateien im Dateisystem oder in der Datenbank. Welche Dateitypen Sie auswählen können, hängt davon ab, wo Sie das Bild hochladen.

Ist am Ziel bereits eine Datei mit demselben Namen vorhanden, können Sie im Konfliktdialog die vorhandene Datei ersetzen, die neue Datei umbenennen oder den Upload überspringen.
