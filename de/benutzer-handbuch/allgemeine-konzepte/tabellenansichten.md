# Tabellenansichten

## Tabellenansichten durchsuchen

Ist links neben einer Tabelle ein Filtersymbol vorhanden, können Sie die angezeigten Einträge eingrenzen. Kombinieren Sie dafür bis zu drei Kriterien wie Name, Wert und Shop. Ein Klick auf das Fragezeichen zeigt die verfügbaren Filteroptionen:

![](<../../.gitbook/assets/2022-10-04 11_44_40-Alle Einstellungen (fortgeschritten) _ Smartstore Administration.png>)

Um das Tabellenlayout anzupassen, klicken Sie unten rechts auf das Zahnradsymbol.

![](<../../.gitbook/assets/2022-10-04 11_49_54-Alle Einstellungen (fortgeschritten) _ Smartstore Administration.png>)

## Produktauswahl

Für die Produktauswahl verwendet der Administrationsbereich überall dieselbe Komponente. Mit der Filterfunktion links oberhalb der Tabelle suchen Sie nach Produktnamen oder grenzen die Liste nach Warengruppe, Hersteller, Shop oder Produkttyp ein.

![](<../../.gitbook/assets/2022-10-04 11_56_13-Produktverwaltung _ Smartstore Administration.png>)

Auch das Layout der Produktansicht können Sie nach Wunsch gestalten. Klicken Sie dazu unten rechts auf das Zahnradsymbol.

![](<../../.gitbook/assets/2022-10-04 11_58_06-Produktverwaltung _ Smartstore Administration.png>)
