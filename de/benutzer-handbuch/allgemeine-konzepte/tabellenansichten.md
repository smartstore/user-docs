# Tabellenansichten

## Tabellenansichten durchsuchen

Sie können die Einträge in einer Tabellenansicht filtern, indem Sie auf das Filtersymbol auf der linken Seite der Tabelle klicken, sofern eines vorhanden ist. Die angezeigten Einträge können mit bis zu drei kombinierten Kriterien (Name, Wert, Shop) gefiltert werden. Die Filteroptionen, die angewendet werden können, werden nach dem Klick auf das Fragezeichen eingeblendet:

![](<../../.gitbook/assets/2022-10-04 11_44_40-Alle Einstellungen (fortgeschritten) _ Smartstore Administration.png>)

Sie können das Layout der Tabellenansicht nach Wunsch gestalten. Klicken Sie dazu unten rechts auf das Zahnradsymbol.

![](<../../.gitbook/assets/2022-10-04 11_49_54-Alle Einstellungen (fortgeschritten) _ Smartstore Administration.png>)

## Produktauswahl

Im Administrationsbereich gibt es viele Stellen, an denen Sie ein Produkt aus Ihrem bestehenden Katalog auswählen müssen. Dies tun Sie stets mit der gleichen Auswahlkomponente. Um das gewünschte Produkt zu finden, gibt es eine leicht zu bedienende Filterfunktion links oberhalb der Tabelle, in der Ihre Produkte angezeigt werden. Sie können u. a. nach dem Produktnamen suchen oder alle Produkte einer bestimmten Warengruppe, eines bestimmten Herstellers, eines bestimmten Shops oder eines bestimmten Produkttyps anzeigen lassen.

![](<../../.gitbook/assets/2022-10-04 11_56_13-Produktverwaltung _ Smartstore Administration.png>)

Auch das Layout der Produktansicht können Sie nach Wunsch gestalten. Klicken Sie dazu unten rechts auf das Zahnradsymbol.

![](<../../.gitbook/assets/2022-10-04 11_58_06-Produktverwaltung _ Smartstore Administration.png>)
