# AddToAny

Das [AddToAny](https://www.addtoany.com/)-Plugin fügt ausgewählten Seiten ein Widget hinzu, über das Besucher Inhalte in verschiedenen Social-Media- und Kommunikationsdiensten teilen können.

![AddToAny-Widget auf der Startseite](../../.gitbook/assets/addtoany_frontend.png)

## Voraussetzung

Für die Anzeige des Widgets müssen folgende Voraussetzungen erfüllt sein:

* **Cookies von Drittanbietern** müssen im **Cookie-Manager** zugelassen sein.

## Einstellungen

Die Konfiguration erfolgt über die Plugin-Einstellungen (Plugins → AddToAny). Unter anderem können die **Art der Platzierung**, das **Design des Widgets**, die **angebotenen Dienste** und die **verwendeten Seiten** festgelegt werden.

![AddToAny Konfiguration](../../.gitbook/assets/addtoany_config.png)

Die im Widget verfügbaren Dienste können über das Dropdown-Menü ausgewählt und hinzugefügt werden.

![AddToAny Konfiguration](../../.gitbook/assets/addtoany_config_services.png)
