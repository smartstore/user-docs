# Ereignistypen einrichten

In einem Shop gibt es Vorgänge, die täglich mehrfach auftreten. Smartstore protokolliert diese im **Aktivitätslog**, das Sie unter **Kunden > Aktivitätslog** aufrufen können. Bei der Installation von Smartstore werden unterschiedliche Ereignistypen angelegt. Bei einer Neuinstallation sind viele administrative Ereignisse bereits aktiviert, während Ereignisse aus dem öffentlichen Shop standardmäßig deaktiviert sind. Sie können jedoch selbst entscheiden, welche Aktivitäten für Sie relevant sind und deshalb protokolliert werden sollen. Um die Protokollierung anzupassen, öffnen Sie **Konfiguration > Ereignistypen**. Dort können Sie die Protokollierung bestimmter Ereignisse aktivieren oder deaktivieren. Öffnen Sie den gewünschten Ereignistyp zur Bearbeitung, setzen oder entfernen Sie den Haken bei **Aktiviert** und klicken Sie anschließend auf **Speichern**.

## Einige interessante Ereignistypen

| Ereignistyp                                            | Protokollierte Aktivität                                                                                  |
| ------------------------------------------------------ | --------------------------------------------------------------------------------------------------------- |
| Öffentlicher Shop. Produktrezension hinzugefügt        | Fügt ein Ereignis zum Log hinzu, sobald eine Produktrezension zu einem Ihrer Produkte geschrieben wurde.  |
| Öffentlicher Shop. Bestellung aufgegeben               | Fügt ein Ereignis zum Log hinzu, sobald ein Kunde eine Bestellung aufgegeben hat.                         |
| Öffentlicher Shop. Produkt zur Wunschliste hinzugefügt | Fügt ein Ereignis zum Log hinzu, sobald ein Produkt auf die Wunschliste eines Ihrer Kunden gesetzt wurde. |
